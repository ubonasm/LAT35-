# LAT35++ v0.1

質的研究のためのデータ分析ワークベンチ

Developed by Masanobu Sakamoto

---

## LAT35++ とは

インタビューや授業記録などの発言データ（発言番号・発言者・発言内容）にコードを付し、語やコードの関係を可視化するアプリです。

最大の特徴は、コードに **「度合い」（3段階）** を設定できることです。たとえば同じ「やめて」でも、遊びの中の軽いものと切実なものを区別してコーディングでき、インタビューや授業が進むにつれて話者の切実性が高まっていく様子を可視化できます。

### 主な機能

| 機能 | 内容 |
| --- | --- |
| プロジェクト管理 | 作成・切り替え・自動保存、プロジェクトファイル（`.qda.json`）の保存と読み込み |
| 文書管理 | CSV / TXT の取り込み（UTF-8・Shift_JIS 自動判別） |
| コード管理 | コード名・定義・色・上位カテゴリー・度合い（3段階）・自動コーディング用の語 |
| カテゴリ | 複数のコードを包括する上位概念。説明文と、含むコード・該当箇所の一覧を表示 |
| コーディング | 1発言・複数発言（発言をまたぐ）・発言内の一部分に付与。度合いに応じて太さの変わる縦線で表示 |
| KWIC検索 | 語を検索し、前後の文脈とともに一覧表示 |
| 語の分析 | 頻出語、共起ネットワーク（Jaccard・TF-IDF・コサイン類似度）、多次元尺度構成法（MDS） |
| コードの分析 | コード同士の類似・近接（ヒートマップ・ネットワーク）、度合いの推移 |
| 対応分析 | 語 × コード（または発言者・区間）の対応分析と χ² 検定 |
| ユーザー辞書 | 「日本人」など、分割されてしまう語をプロジェクトごとに登録 |
| 図の保存 | PNG / JPG / PDF / SVG。色「なし」でグレースケール（論文用）にも対応 |
| 一覧表の出力 | カテゴリ・コード一覧表を A4 / Letter 横向き・余白 20mm で印刷・PDF化、CSV・Excel（xlsx）で保存 |

## 動作環境

- **Windows 10 / 11**、**macOS**、**Linux**
- **Node.js 20 以上**（推奨：LTS 版）
- ブラウザ：Chrome、Edge、Firefox、Safari の最新版

インターネット接続は **初回のインストール時のみ** 必要です。インストール後はオフラインで使えます。形態素解析の辞書（kuromoji / IPA辞書）は同梱されています。

---

## インストール

### 1. Node.js をインストールする

まだの場合は [https://nodejs.org/](https://nodejs.org/) から **LTS 版** をダウンロードしてインストールしてください。

インストールできたかは、コマンドプロンプト（Mac は「ターミナル」）で次のように確認できます。

```
node -v
```

`v20.x.x` 以上が表示されれば OK です。

### 2. LAT35++ を展開する

ダウンロードした ZIP ファイルを好きな場所に展開します。

> **注意（Windows）**
> パスに日本語や空白が含まれないフォルダ（例：`C:\LAT35pp`）に置くと、トラブルが起きにくくなります。

### 3. 初回セットアップ（1回だけ）

| OS | 操作 |
| --- | --- |
| Windows | `setup.bat` をダブルクリック |
| Mac / Linux | ターミナルで `./setup.sh` を実行 |

必要なパッケージのインストールとアプリのビルドを行います。数分かかります。「Setup finished.」と表示されたら完了です。

> Mac / Linux で「Permission denied」と出る場合は、先に次を実行してください。
> ```
> chmod +x setup.sh start.sh
> ```

## 起動と終了

### 起動（2回目以降はこれだけ）

| OS | 操作 |
| --- | --- |
| Windows | `start.bat` をダブルクリック |
| Mac / Linux | ターミナルで `./start.sh` を実行 |

数秒後にブラウザが自動で開き、`http://localhost:3000` が表示されます。開かない場合は、ブラウザのアドレス欄に直接入力してください。

※ セットアップをしていない状態で `start` を実行した場合も、自動でセットアップが始まります。

### 終了

黒いウィンドウ（コマンドプロンプト／ターミナル）を閉じるか、そのウィンドウで `Ctrl + C` を押します。作業内容は自動保存されているので、そのまま終了して大丈夫です。

## 使い方

### 1. プロジェクトを作成する／読み込む

画面左上のプロジェクト名をクリックして、次のいずれかを選びます。

- **新しいプロジェクト**：名前を付けて作成
- **プロジェクトを読み込む**：保存しておいた `.qda.json` ファイルを開く

初めて起動したときは、操作を試せるサンプルプロジェクトが開きます。

### 2. テキストを取り込む

左側の文書一覧から CSV または TXT ファイルを取り込みます。

**CSV の場合**：1行目に見出しを付けてください。列名は次のいずれかであれば自動で認識します。

| 項目 | 認識する列名 |
| --- | --- |
| 発言番号 | 発言番号、番号、通し番号、No、ID |
| 発言者 | 発言者、話者、名前、氏名、Speaker |
| 発言内容 | 発言内容、発言、内容、テキスト、Text |

```csv
発言番号,発言者,発言内容
1,T,今日は戦争について考えます。
2,達也,やめてよ、そんなこと言うの。
```

**TXT の場合**：次のような書き方に対応しています。

```
1	T	今日は戦争について考えます。        ← タブ区切り
2 達也：やめてよ、そんなこと言うの。       ← 番号 発言者：内容
達也：やめてよ。                           ← 発言者：内容
```

文字コードは UTF-8 と Shift_JIS（Excel で保存した CSV）のどちらでも読み込めます。

### 3. コードを定義する

コードシステムの **「＋コード」** から作成します。

- **コード名・定義**：コードを付す基準や、含む／含まない例
- **色**：縦線やグラフで使う色
- **上位カテゴリー**：このコードを包括するカテゴリやコード（一覧では `カテ` / `コド` で区別されます）
- **度合い（3段階）**：それぞれの段階の意味（例：1＝遊びの中、2＝やや意図あり、3＝切実）
- **自動コーディング用の語**：読点・カンマ区切りで入力すると、その語を含む発言に自動でコードを付けられます

**「＋カテゴリ」** からは、複数のコードを包括する上位概念を作れます。カテゴリを選択すると、説明文・含むコード・該当する発言が右側に表示されます。

### 4. コードを付す

1. 本文の該当箇所をマウスで選択します（発言をまたいでも、発言の一部だけでも可）。
2. 上部のツールバーでコードと度合いを選び、付与します。
3. コードを付した箇所には、本文の左側に **縦線** が引かれます。度合いが高いほど線が太くなります。

### 5. KWIC検索

検索パネルに語を入力すると、その語の前後の文脈を一覧表示します（KH Coder の KWIC コンコーダンスと同様）。結果を見ながらコードの定義を見直すのに便利です。

### 6. 可視化する

画面上部の **「可視化」** を開き、条件を設定して **「可視化する」** を押します。

- **対象の絞り込み**：文書、発言者、品詞、最小頻度、発言番号の区間
- **注目語**：分析に含めたい語を指定
- **類似度の指標**：Jaccard 係数、TF-IDF、コサイン類似度

| 図 | 表示される統計量 |
| --- | --- |
| 共起ネットワーク | N（語数）、E（エッジ数）、D（密度）、グループ数（modularity） |
| 多次元尺度構成法 | Kruskal Stress-1、累積寄与率 |
| 対応分析 | 総慣性、累積寄与率、χ² 値・自由度・p 値 |
| コードの類似・近接 | ヒートマップ・ネットワーク |
| 度合いの推移 | 発言番号の進行に伴う度合いの変化 |

**色の設定**で **「なし」** を選ぶと、白黒（グレースケール）で表示されます。論文や報告書に載せるときに便利です。

各図の右上から **PNG / JPG / PDF / SVG** で保存できます。SVG はベクター形式なので、Illustrator・Inkscape・PowerPoint などで拡大しても粗くならず、文字や線を後から編集できます。

### 7. 語の分割を直す（ユーザー辞書）

「日本人」が「日本」「人」に分かれてしまうなど、語の分割のされ方が意図と違う場合は、可視化画面の **「語の取り扱い（辞書）」** で語を登録してください。登録はプロジェクトごとに保存されます。

### 8. カテゴリ・コード一覧表を作る

コードシステム下部の **「カテゴリ・コード一覧作成」** を押すと、次の列の一覧表が表示されます。

カテゴリ ／ カテゴリ定義 ／ コード ／ 付された発言番号 ／ 付された文章

用紙サイズ（A4 / Letter）を選び、**「印刷／PDF」** を押します。PDF にする場合は、印刷画面の送信先で「PDF に保存」を選んでください。用紙は横向き、余白は上下左右 20mm に設定されています。

**「CSV」** または **「Excel (xlsx)」** を押すと、同じ内容を表データとして保存できます（列：カテゴリ ／ カテゴリ定義 ／ コード ／ 発言番号 ／ 付された文章 ／ 度合い。文書が複数ある場合は「文書」列も加わります）。CSV は Excel で開いても文字化けしない UTF-8（BOM 付き）で保存されます。

## 保存とデータの受け渡し

### 自動保存

作業内容は、操作するたびに **ブラウザの中に自動保存** されます。アプリを終了して再び起動すれば、続きから作業できます。

> **注意**
> 自動保存はブラウザごとに行われます。ブラウザの履歴やサイトデータを消去すると、保存内容も消えてしまいます。大切なデータは、次の方法でファイルとしても保存してください。

### プロジェクトファイルとして保存

画面上部の **「ファイルに保存」** を押すと、プロジェクト全体（文書・コード・カテゴリ・コーディング・ユーザー辞書）が `.qda.json` ファイルとしてダウンロードされます。

- **バックアップ**：定期的に保存しておくと安心です。
- **ほかの人に渡す**：`.qda.json` を渡し、相手が「プロジェクトを読み込む」で開くと、同じ状態から作業を続けられます。
- **別の PC で続ける**：同じ手順で移せます。

データはすべて自分の PC の中だけで処理されます。インターネット上に送信されることはありません。

## 困ったときは

| 症状 | 対処 |
| --- | --- |
| `setup.bat` で「Node.js was not found」と出る | Node.js をインストールし、PC を再起動してからもう一度実行してください。 |
| 起動時に「port 3000 is already in use」と出る | LAT35++ がすでに起動しています。前のウィンドウを閉じてから起動し直してください。 |
| ブラウザが自動で開かない | ブラウザで `http://localhost:3000` を開いてください。 |
| CSV の文字が化ける | Excel で「CSV UTF-8」形式で保存し直してください。 |
| 語が意図通りに分割されない | 「語の取り扱い（辞書）」で語を登録してください。 |
| 更新後にうまく動かない | `.next` フォルダを削除してから `start.bat`（`start.sh`）を実行してください。再ビルドされます。 |

pnpm build       # 本番用ビルド
